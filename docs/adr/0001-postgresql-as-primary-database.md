# ADR-001. PostgreSQL как основная система управления базами данных

Статус: принято. Дата: 04.11.2026.

## Контекст
Система хранит брони, поездки и расчёты (реляционные данные с транзакциями) и поток телеметрии
(десятки тысяч записей в сутки на автомобиль парка). Требуются транзакционность, работа с
географическими данными и отсутствие лицензионных платежей. Стек серверной части — .NET 8.

## Решение
Использовать PostgreSQL 16 как единую СУБД. Доступ из .NET — через Entity Framework Core и драйвер Npgsql.
Телеметрия хранится в таблице `telemetry_records` с партиционированием по месяцам.

## Последствия
- Положительные: бесплатная лицензия, транзакции ACID, типы `timestamptz`, `numeric`, `text[]`, расширение PostGIS для геозон.
- Отрицательные: объём телеметрии потребует партиционирования и архивации; команде нужно освоить администрирование PostgreSQL.
- Отвергнутые альтернативы: Microsoft SQL Server (стоимость лицензий), MongoDB (слабые транзакции для расчётов).
