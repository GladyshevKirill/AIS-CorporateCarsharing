# АИС «Корпоративный каршеринг»

Учебный проект по МДК 02.02 (СПбИЭУ), вариант 6. Автор: Гладышев Кирилл Алексеевич, группа И14-23-9А.

Система обеспечивает бронирование служебных автомобилей, приём телеметрии GPS/OBD и биллинг
(расчёты с подразделениями, интеграция с 1С).

## Структура репозитория

| Каталог | Назначение |
|---|---|
| `src/AIS.Core` | Доменная модель и интерфейсы (не зависит от других проектов) |
| `src/AIS.Infrastructure` | Доступ к данным, приём телеметрии, интеграция с 1С |
| `src/AIS.Api` | Серверное приложение ASP.NET Core |
| `src/AIS.UI` | Клиентское приложение WPF (MVVM) |
| `tests/AIS.Tests` | Модульные тесты xUnit |
| `docs/requirements` | Требования и сценарии использования |
| `docs/architecture` | Диаграммы C4 |
| `docs/openapi` | Спецификация API |
| `docs/adr` | Записи архитектурных решений |
